# SalaryClock

지금 이 순간 내 월급이 얼마나 쌓였는지 보여주는 시계.

**https://sc.vicals.com**

연봉과 근무시간을 한 번 넣어두면, 출근한 순간부터 초 단위로 올라가는 금액을
보여줍니다. 가입도 설치도 필요 없고, 맥에서는 메뉴바에 띄워두고 쓸 수 있습니다.

```
            2026년 9월 22일 (화)
     09:00–18:00 · 유급 8시간 · 이번 달 20일

              ╭─────────╮
            ╱   12        ╲          바깥 링이 하루 진행률
           │  9  ╲│    3   │         점심 구간은 비어 있음
            ╲      6      ╱
              ╰─────────╯

            ₩ 83,333.3   [세전]
                +5.8 / 초

        퇴근까지 04:00:00 · 남은 ₩83,333
```

## 무엇을 보여주나

- **초 단위로 올라가는 오늘 적립 금액.** 소수 첫째 자리까지 흘러서 멈춰 있지 않습니다.
- **퇴근까지 남은 시간과 남은 금액.**
- **실수령액 기준 전환.** 4대보험과 소득세를 뺀 금액으로 볼 수 있습니다.
- **점심시간은 빼고 셉니다.** 시계 링에서도 그 구간이 비어 있습니다.
- **시계 얼굴 10종.** 말끔·숫자판·결·고리·채움·점·남은·수위·해시계·파문.
- **금액 가리기.** 켜면 시계와 시각만 남습니다.
- **퇴근 후에는 인사말.** 내일도 근무인지, 주말인지, 연휴인지에 따라 다르게 나옵니다.

## 어떻게 쓰나

오른쪽 위 톱니바퀴를 눌러 설정을 엽니다.

**급여** — 연봉·월급·시급 중에 고르고 금액을 넣습니다. 억·만 단위로 읽어주니
0의 개수를 세지 않아도 됩니다. *실수령액 기준으로 보기*를 켜면 공제를 뺀 금액이
나옵니다. 공제율을 직접 넣을 수도 있습니다.

**근무 시간** — 출근·퇴근 시각을 넣습니다. 자정을 넘기는 야간 근무도 됩니다.

**점심** — 시작과 끝 시각으로 넣습니다. 그 시간만큼은 돈이 붙지 않습니다.

**근무일수** — 월급제라면 하루 벌이가 `월급 ÷ 근무일수`로 정해지므로 이 숫자가
금액을 좌우합니다. 세 가지로 정할 수 있습니다.

- 그대로 두면 **평일에서 공휴일을 뺀 수**를 씁니다.
- 달력에서 날짜를 누르면 그날을 쉬는 날로, 다시 누르면 근무일로 바꿉니다.
  회사 휴무일이나 연차를 반영할 때 씁니다.
- 숫자를 직접 고쳐 넣어도 됩니다.

시계 얼굴은 설정 맨 위에서 고르고, 가리기와 밝게/어둡게는 화면 오른쪽 위
아이콘으로 바로 켭니다.

## 맥 메뉴바 앱

브라우저를 열지 않고 메뉴바에 금액을 띄워둘 수 있습니다. 누르면 시계와 상세가
담긴 창이 떨어지고, 가리기를 켜면 아이콘만 남아서 옆에서 보면 그냥 시계입니다.

### 설치

[릴리스 페이지](https://github.com/woosublee/SalaryClock/releases/latest)에서
DMG를 받아 응용 프로그램 폴더에 넣으면 됩니다.

**첫 실행은 macOS가 막습니다.** 개인이 서명한 앱이라 그렇습니다. 한 번만 아래처럼
열어주면 그다음부터는 그냥 열립니다.

- macOS 13·14: Finder에서 앱을 Control-클릭하고 **열기**를 고릅니다.
- macOS 15 이상: 한 번 실행해 본 뒤 **시스템 설정 > 개인정보 보호 및 보안 > 보안**에서
  **그래도 열기**를 누릅니다.

### 맥에서만 있는 것

- **새 버전 자동 확인.** 앱을 열 때와 하루에 한 번 확인합니다. 설정에서 자동 설치를
  켜두면 묻지 않고 받아서 깔아줍니다.
- **로그인할 때 자동 실행.**
- **메뉴바 갱신 주기.** 기본 1초이고 0.1초까지 줄일 수 있습니다. 짧을수록 숫자가
  부드럽게 흐르지만 배터리를 조금 더 씁니다.

설정 내용은 웹과 따로 저장됩니다. 웹에서 넣은 값이 앱으로 넘어오지 않으니 한 번은
다시 넣어야 합니다.

## 알아두면 좋은 것

**내 급여 정보는 어디로도 나가지 않습니다.** 서버도 계정도 없습니다. 입력한 값은
브라우저(맥 앱은 기기)에만 저장되고, 금액 계산도 전부 그 안에서 일어납니다.

**소득세는 추정치입니다.** 4대보험은 법정 요율이라 정확하지만, 소득세는 부양가족
수나 비과세 수당 같은 것을 알 수 없어 근사했습니다. 명세서와 차이가 나면 설정에서
공제율을 직접 넣으세요. 명세서의 `공제 합계 ÷ 세전 금액`을 넣으면 맞습니다.

**공휴일은 2026·2027년까지 들어 있습니다.** 음력 공휴일과 대체공휴일은 매년 관보로
정해져서 미리 계산할 수 없습니다. 표에 없는 해는 주말만 빼고 세면서 화면에 그 사실을
알려줍니다. 근로자의 날(5월 1일)은 회사마다 달라서 빼지 않았습니다.

**금액 가리기는 보안 기능이 아닙니다.** 화면에 안 보이게 할 뿐이라, 옆자리에서
화면이 보일 때 쓰는 정도로 생각하세요.

**설정은 브라우저마다 따로입니다.** 크롬에서 넣은 값이 사파리나 폰으로 넘어가지
않습니다.

**시계는 어긋나지 않습니다.** 적립 금액을 어디에 저장해두고 더해가는 것이 아니라,
매 순간 설정과 현재 시각으로 다시 계산합니다. 탭을 닫았다 열어도, 노트북이 절전에서
깨어나도 값이 맞습니다.

## 직접 고쳐 쓰려면

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # 계산 로직 테스트
```

맥 앱은 Swift로 되어 있고 `macos/`에 있습니다. 계산 규칙은 웹과 공유하며
(`shared/golden/*.json`을 양쪽 테스트가 함께 읽습니다), 규칙이 갈라지면 한쪽 테스트가
실패합니다.

```bash
./scripts/create-signing-certificate.sh   # 처음 한 번만
./scripts/install-app.sh                  # 빌드해서 /Applications에 설치

npm run swift:test:core                   # 계산 규칙
npm run swift:test:app                    # 앱 동작
```

버전을 올리고 태그를 밀면 GitHub Actions가 빌드부터 릴리스 발행까지 합니다.

아이콘은 그림 파일이 아니라 코드입니다. 색을 웹에서 뽑아 쓰기 때문에 팔레트가 바뀌면
아이콘도 따라 바뀝니다. 맥 앱은 빌드할 때마다 그리고, 웹 파비콘은
`./scripts/generate-web-icons.sh`로 다시 만듭니다.

설계와 결정의 배경은
[`docs/superpowers/specs/2026-09-22-macos-menubar-design.md`](docs/superpowers/specs/2026-09-22-macos-menubar-design.md)에
적어두었습니다. Next.js와 TypeScript, Tailwind로 만들었고 서버 코드는 없습니다.
