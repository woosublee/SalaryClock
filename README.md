# SalaryClock

지금 이 순간 내 월급이 얼마나 쌓였는지 보여주는 시계.

연봉과 근무시간을 한 번 입력해두면, 출근한 순간부터 초 단위로 적립되는 금액과
끊김 없이 흐르는 아날로그 시계를 한 화면에서 보여줍니다.

서버도 데이터베이스도 로그인도 없습니다. 전부 브라우저 안에서 끝납니다.

## 무엇을 보여주나

```
            2026년 9월 22일 (화)
     09:00–18:00 · 유급 8시간 · 이번 달 20일

              ╭─────────╮
            ╱   12        ╲          아날로그 시계
           │  9  ╲│    3   │         바깥 링 = 근무 진행률
            ╲      6      ╱          점심 구간은 비어 있음
              ╰─────────╯

            ₩ 83,333.3   [세전]
                +5.8 / 초

        퇴근까지 04:00:00 · 남은 ₩83,333
```

- 초 단위(소수 1자리)로 올라가는 적립 금액
- 시계 링이 곧 하루 진행률 — 점심시간은 비어 있어 "여기는 돈이 안 붙는다"가 보임
- 퇴근까지 남은 시간과 남은 금액
- 실수령액 기준 전환 (4대보험 + 소득세 추정)
- 시계 얼굴 10종
- 금액 가리기 (옆자리에서 화면 보일 때)

## 설계에서 신경 쓴 것

**저장되는 상태는 설정값뿐입니다.** 적립 금액은 어디에도 저장하지 않고 매 프레임
`f(설정, 현재시각)`으로 새로 계산합니다. 탭을 닫았다 열어도, 노트북이 절전에서
깨어나도, 시계가 어긋날 구조적 여지가 없습니다.

**시간 소스는 `requestAnimationFrame` 틱 하나뿐입니다.** 초침이 1초마다 끊기지 않고
스르륵 흐르고(스위프), 시계 바늘과 금액이 같은 틱에서 나와 서로 어긋나지 않습니다.
바늘 회전에 CSS transition을 걸지 않는 것도 같은 이유입니다 — 360°에서 0°로 넘어갈 때
역방향으로 한 바퀴 돌아버립니다.

**계산 로직은 전부 순수 함수입니다.** `lib/` 아래 함수들은 `Date.now()`를 직접
호출하지 않고 현재 시각을 인자로 받습니다. 덕분에 자정을 넘는 야간근무나 점심 경계
같은 케이스를 브라우저 없이 전부 테스트로 잡았습니다.

**월급제의 성질을 지킵니다.** 일급은 `월급 ÷ 근무일수`로 정해지므로 그날 8시간을
일하든 7시간을 일하든 받는 돈은 같고, 초당 단가만 달라집니다. 시급제는 반대로
움직입니다. 둘 다 테스트로 고정해 두었습니다.

## 구조

| 경로 | 역할 |
|---|---|
| `lib/time.ts` | `"HH:mm"` 파싱, 분↔ms 변환 |
| `lib/settings.ts` | 설정 스키마(zod), 기본값, localStorage |
| `lib/shift.ts` | 설정 + 현재시각 → 근무 시프트의 절대 시각 |
| `lib/salary.ts` | 시프트 + 현재시각 → 적립액·진행률·남은 시간 |
| `lib/clock.ts` | 바늘 각도, 문자판 호 |
| `lib/deductions.ts` | 4대보험·소득세 추정 |
| `lib/holidays.ts` | 대한민국 공휴일 표 (2026·2027) |
| `lib/workdays.ts` | 월별 근무일수 |
| `lib/calendar.ts` | 달력에서 쉬는 날 고르기 |
| `hooks/useNow.ts` | rAF 틱. 앱의 유일한 시간 소스 |
| `components/clock/` | 시계 얼굴 10종 |

의존 방향은 `time → settings → shift → {salary, clock}` 한 방향입니다.

## 알아두면 좋은 것

**소득세는 추정치입니다.** 4대보험은 법정 요율이라 정확하지만, 소득세는 간이세액표를
그대로 옮길 수 없어 연말정산 구조를 따라 근사했습니다. 부양가족 수, 비과세 수당,
각종 공제가 빠져 있어 실제 명세서와 차이가 납니다. 설정에서 공제율을 직접 덮어쓸 수
있으니 명세서의 `공제 합계 ÷ 세전 금액`을 넣으면 정확해집니다.

**공휴일 표는 2026·2027년만 들어 있습니다.** 음력 공휴일과 대체공휴일은 매년 관보로
확정되어 계산으로 뽑을 수 없습니다. 표에 없는 해는 주말만 빼는 방식으로 되돌아가고,
화면에 그 사실을 표시합니다. 낡은 표를 조용히 쓰는 것보다 모른다고 말하는 편이 낫다고
봤습니다. 근로자의 날(5/1)은 관공서 공휴일이 아니라 회사마다 갈려서 빼지 않았습니다.

**금액 가리기는 보안 기능이 아닙니다.** 블러는 화면을 가릴 뿐이고 텍스트는 DOM에
그대로 있습니다. 옆자리에서 화면 보일 때 쓰는 정도입니다.

**설정은 브라우저별·기기별로 저장됩니다.** localStorage를 쓰므로 크롬에서 설정한 게
사파리나 폰으로 넘어가지 않습니다.

## 맥 메뉴바 앱

금액을 메뉴바에 직접 띄우는 네이티브 앱이 `macos/`에 있다.

```bash
./scripts/install-app.sh      # 빌드해서 /Applications에 설치
open /Applications/SalaryClock.app
```

계산 규칙은 웹과 공유한다 — `shared/golden/*.json`을 양쪽 테스트가 함께
읽으므로, 규칙이 갈라지면 한쪽이 빨개진다.

```bash
npm test                # 웹
npm run swift:test:core # 맥 (SalaryClockCore)
```

`swift test`를 손으로 직접 돌릴 거라면 `--package-path`만으로는 안 된다 —
이 저장소는 iCloud 동기화 폴더 안에 있어 `--scratch-path`를 따로 줘야
한다. 이유와 정확한 명령은 설계 문서 10장에 있다.

설계와 이식 결정은 `docs/superpowers/specs/2026-09-22-macos-menubar-design.md`에
있다.
