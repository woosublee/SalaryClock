# SalaryClock

근무 시간 동안 쌓이는 급여를 실시간으로 보여주는 시계입니다.

**https://sc.vicals.com**

급여와 근무 시간을 한 번 입력하면 출근 시각부터 적립되는 금액을 초 단위로
표시합니다. 별도의 가입이나 설치 없이 브라우저에서 바로 사용할 수 있으며,
macOS에서는 메뉴바 앱으로도 제공됩니다.

```
            2026년 9월 22일 (화)
     09:00–18:00 · 유급 8시간 · 이번 달 20일

              ╭─────────╮
            ╱   12        ╲          바깥 링: 하루 진행률
           │  9  ╲│    3   │         점심 구간은 비어 있음
            ╲      6      ╱
              ╰─────────╯

            ₩ 83,333.3   [세전]
                +5.8 / 초

        퇴근까지 04:00:00 · 남은 ₩83,333
```

## 주요 기능

- **실시간 적립 금액** — 소수점 첫째 자리까지 표시하여 값이 연속적으로 변합니다.
- **퇴근까지 남은 시간과 금액**
- **실수령액 기준 전환** — 4대보험과 소득세를 공제한 금액으로 볼 수 있습니다.
- **점심시간 제외** — 무급 구간은 적립에서 빠지며, 시계 링에서도 비어 있게 표시됩니다.
- **시계 얼굴 10종** — 말끔, 숫자판, 결, 고리, 채움, 점, 남은, 수위, 해시계, 파문
- **금액 가리기** — 활성화하면 시계와 시각만 남습니다.
- **퇴근 후 안내 문구** — 다음 근무일이 언제인지에 따라 다른 문구를 표시합니다.

## 설정

화면 오른쪽 위의 설정 아이콘에서 다음 항목을 지정합니다.

| 항목 | 설명 |
|---|---|
| 급여 | 연봉, 월급, 시급 중 선택하여 금액을 입력합니다. 입력한 금액은 억·만 단위로 함께 표시됩니다. |
| 실수령액 기준 | 4대보험과 소득세를 공제한 금액으로 계산합니다. 공제율을 직접 지정할 수도 있습니다. |
| 근무 시간 | 출근과 퇴근 시각을 입력합니다. 자정을 넘기는 야간 근무도 지원합니다. |
| 점심시간 | 시작과 종료 시각으로 입력하며, 해당 구간은 무급으로 처리됩니다. |
| 근무일수 | 아래 세 가지 방식 중 하나로 정합니다. |
| 시계 얼굴 | 열 가지 중에서 선택합니다. |

월급제에서는 하루 급여가 `월급 ÷ 근무일수`로 결정되므로 근무일수가 적립 속도를
좌우합니다. 다음 세 가지 방식을 지원합니다.

1. **자동** — 해당 월의 평일에서 공휴일을 제외한 일수를 사용합니다.
2. **달력에서 지정** — 날짜를 클릭하여 휴무일과 근무일을 직접 전환합니다. 회사
   휴무일이나 연차를 반영할 때 사용합니다.
3. **직접 입력** — 일수를 숫자로 입력합니다.

금액 가리기와 밝게·어둡게 전환은 화면 오른쪽 위 아이콘에서 바로 사용할 수 있습니다.

## macOS 메뉴바 앱

메뉴바에 적립 금액을 상시 표시하는 네이티브 앱입니다. 메뉴바 항목을 클릭하면
시계와 상세 정보가 담긴 팝오버가 열리며, 금액 가리기를 켜면 아이콘만 남습니다.

### 설치

[릴리스 페이지](https://github.com/woosublee/SalaryClock/releases/latest)에서
DMG를 내려받아 응용 프로그램 폴더로 옮깁니다.

이 앱은 Apple 공증(notarization)을 거치지 않은 자체 서명 앱이므로 macOS가 최초
실행을 차단합니다. 아래 절차로 한 번 허용하면 이후에는 정상적으로 실행됩니다.

- **macOS 13–14** — Finder에서 앱을 Control-클릭한 뒤 **열기**를 선택합니다.
- **macOS 15 이상** — 실행을 한 번 시도한 뒤 **시스템 설정 › 개인정보 보호 및 보안 ›
  보안**에서 **그래도 열기**를 선택합니다.

### macOS 전용 기능

| 항목 | 설명 |
|---|---|
| 자동 업데이트 | 앱 실행 시와 하루에 한 번 새 버전을 확인합니다. 설정에서 자동 설치를 켜면 확인 없이 내려받아 설치합니다. |
| 로그인 시 자동 실행 | 로그인 항목으로 등록합니다. |
| 메뉴바 갱신 주기 | 기본값은 1초이며 0.1초까지 줄일 수 있습니다. 주기가 짧을수록 표시가 부드러워지지만 전력을 조금 더 사용합니다. |

설정값은 웹과 별도로 저장되므로 앱에서 한 번 다시 입력해야 합니다.

## 참고 사항

**입력한 급여 정보는 외부로 전송되지 않습니다.** 서버와 계정이 없으며, 설정값은
브라우저(앱의 경우 기기)에만 저장되고 모든 계산은 로컬에서 수행됩니다.

**소득세는 추정치입니다.** 4대보험은 법정 요율을 적용하므로 정확하지만, 소득세는
부양가족 수와 비과세 수당 등을 알 수 없어 근사치로 계산합니다. 급여명세서와 차이가
있다면 설정에서 공제율을 직접 입력하십시오. 명세서의 `공제 합계 ÷ 세전 금액`을
입력하면 실제 금액과 일치합니다.

**공휴일 정보는 2026년과 2027년까지 포함되어 있습니다.** 음력 공휴일과 대체공휴일은
매년 관보로 확정되어 사전 계산이 불가능합니다. 정보가 없는 연도는 주말만 제외하여
계산하며 해당 사실을 화면에 표시합니다. 근로자의 날(5월 1일)은 사업장마다 달라
제외하지 않았습니다.

**금액 가리기는 보안 기능이 아닙니다.** 화면 표시만 가릴 뿐이므로 주변 시선을
차단하는 용도로만 사용하십시오.

**설정은 브라우저별로 저장됩니다.** 한 브라우저에서 입력한 값이 다른 브라우저나
기기로 이어지지 않습니다.

**표시 값은 누적되지 않습니다.** 적립 금액을 저장한 뒤 더해가는 방식이 아니라 매
시점의 설정과 현재 시각으로 새로 계산합니다. 탭을 닫았다 열거나 절전 모드에서
복귀해도 값이 어긋나지 않습니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # 계산 로직 테스트
```

macOS 앱은 Swift로 작성되어 `macos/`에 있습니다. 계산 규칙은 웹과 공유하며,
`shared/golden/*.json`을 양쪽 테스트가 함께 읽으므로 규칙이 어긋나면 한쪽 테스트가
실패합니다.

```bash
./scripts/create-signing-certificate.sh   # 최초 1회
./scripts/install-app.sh                  # 빌드 후 /Applications에 설치

npm run swift:test:core                   # 계산 규칙
npm run swift:test:app                    # 앱 동작
```

버전을 올리고 태그를 푸시하면 GitHub Actions가 빌드부터 릴리스 발행까지 수행합니다.

아이콘은 이미지 파일이 아니라 코드로 그립니다. 색상을 웹 빌드 결과에서 추출해
사용하므로 팔레트가 바뀌면 아이콘도 함께 바뀝니다. macOS 앱은 빌드할 때마다
생성하며, 웹 파비콘은 `./scripts/generate-web-icons.sh`로 다시 만듭니다.

설계 배경과 구현 결정은
[설계 문서](docs/superpowers/specs/2026-09-22-macos-menubar-design.md)에
정리되어 있습니다. Next.js, TypeScript, Tailwind CSS로 작성했으며 서버 코드는
없습니다.
